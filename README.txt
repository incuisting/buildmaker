# 古建筑3D模型展示系统

## 离线使用说明

本系统已优化为可在Windows 10电脑上离线使用。请按照以下步骤操作：

### 一、直接打开方式
1. 右键点击index.html文件，选择"打开方式" -> 选择浏览器（推荐使用Chrome、Edge或Firefox）
2. 如果浏览器显示安全警告，可能需要更改浏览器设置或使用以下方法

### 二、使用本地服务器（推荐，解决安全限制问题）
1. 安装Visual Studio Code（如果尚未安装）
2. 安装"Live Server"插件
3. 在VS Code中打开项目文件夹
4. 右键点击index.html，选择"Open with Live Server"
5. 系统将自动在浏览器中打开项目

### 三、可能遇到的问题及解决方案

#### 1. 无法显示3D模型
- 检查build目录是否包含所有建筑的子目录
- 确保每个子目录包含对应的.obj和.mtl文件

#### 2. 图标不显示
- 确保webfonts文件夹在项目根目录中
- 确保all.min.css文件存在且未损坏

#### 3. 浏览器安全限制
Windows上直接打开HTML文件时，浏览器可能会阻止某些功能。解决方法：
- 使用上述"使用本地服务器"的方法
- 或修改浏览器安全设置（不推荐）

#### 4. 页面加载慢
- 3D模型文件较大，首次加载可能需要一些时间，请耐心等待

### 四、注意事项
- 修改模型文件时，需同时更新buildConfig.js中的配置
- 添加新的建筑时，需在buildConfig.js和buildingNames中添加对应配置
